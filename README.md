# Apology Letter Website

موقع عربي بسيط وتفاعلي لرسالة اعتذار.

## التشغيل

افتح `index.html` مباشرة في المتصفح.

## النشر على Vercel

هذا مشروع static، لذلك يكفي ربط المستودع على GitHub مع Vercel. استخدم الإعدادات الافتراضية:

- Framework Preset: Other
- Build Command: اتركه فارغ
- Output Directory: اتركه فارغ
